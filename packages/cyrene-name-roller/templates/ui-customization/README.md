# Cyrene UI Customization

API 1.3 example using stable component IDs, optional component hiding, a declarative native slot view and a host-bound result presentation.

The plugin never supplies winner names or result arrays. `draw-now` submits an intent to the host-owned draw transaction.

On Windows/Tauri, `desktop-check` calls the declared fixed `system.execute` operation. The same command is unavailable on Web and other platforms; no arbitrary program, arguments or network URL can be supplied by the plugin.
